ABOUT THE PROJECT

Movie Discover

A responsive vanilla JavaScript movie discovery application built as a Web Development II project.

TMDB API

Provides movie search, popular and trending movies, genres, ratings, release dates, posters, backdrops, and movie details.

Visit TMDB

YouTube Data API

Used to find official movie trailers and related video results for the movie details view.

YouTube API docs

Technology

HTML, CSS, and modern vanilla JavaScript with ES modules, Fetch API, URL parameters, and localStorage.

Accessibility

The interface uses semantic HTML, labels, keyboard-friendly controls, visible focus states, responsive layouts, and live status messages.
